# Procédure de gouvernance des données

## 1. Objet

La présente procédure définit les rôles, les règles et les contrôles relatifs à la gestion des données de la banque. Elle a été élaborée dans le cadre du programme Horizon Data et relève du Pôle Architecture et Data. M. Youssef Amrani, architecte data au sein de ce pôle, en est le propriétaire.

## 2. Rôles

- Data owner : responsable métier d'un domaine de données ; il valide les règles de gestion et les droits d'accès.
- Data steward : garant opérationnel de la qualité des données du domaine.
- Équipe plateforme : administre la plateforme DataLake Horizon.

## 3. Référencement des données

Toute donnée chargée dans DataLake Horizon est référencée dans le catalogue de données avec son data owner, sa classification et sa durée de conservation.

## 4. Qualité des données

Des contrôles qualité des données (complétude, unicité, validité, fraîcheur) sont exécutés à chaque chargement. Un indicateur de qualité inférieur à 95 % bloque la publication du jeu de données.

## 5. Données personnelles

Les données personnelles sont pseudonymisées dès leur chargement, sauf exception validée. Mme Ghita Sebti, juriste à la Direction Juridique, rend un avis sur chaque nouveau traitement de données personnelles.

## 6. Accès

Les accès aux jeux de données sont attribués selon la procédure de gestion des habilitations PRC-SEC-004.
