# Knowledge Graph et LLM pour la gestion des connaissances

Projet de fin d'études de Master Data Engineering : plateforme de gestion des connaissances fondée sur un Knowledge Graph (Neo4j) enrichi par un LLM, avec recherche hybride RAG / GraphRAG, contrôle d'accès, citations vérifiées et évaluation expérimentale, appliquée à une banque **fictive** (corpus 100 % synthétique).

Tout le projet se trouve dans le dossier [`RAG/`](RAG) :

- présentation, démarrage rapide et résultats : [`RAG/README.md`](RAG/README.md) ;
- index des livrables : [`RAG/README_LIVRABLES.txt`](RAG/README_LIVRABLES.txt) ;
- documentation pédagogique : [`RAG/DETAILS/GUIDE_COMPLET.txt`](RAG/DETAILS/GUIDE_COMPLET.txt) ;
- mémoire et présentation : [`RAG/RAPPORT ET PRESENTATION/`](RAG/RAPPORT%20ET%20PRESENTATION).

Prototype évalué localement ; aucun déploiement distant réalisé ; aucune mesure avec un vrai LLM (mode hors-ligne).
